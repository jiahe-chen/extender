### Key Insights
----------------------------------------

1. OVERALL EFFECTIVENESS
   - gemma3-4b: +148% relative improvement (13.8% -> 34.2%)
   - llama3-2-3b: +20% relative improvement (33.3% -> 40.0%)

2. PRINCIPLE-SPECIFIC FINDINGS

   Improved Significantly:
   - DIP: +60.4% avg (feedback loop helps identify concrete dependencies)
   - SRP: +19.8% avg (evaluator catches missed multiple responsibilities)

   Remained Challenging:
   - LSP: ~1% avg (requires behavioral subtyping understanding)
   - OCP: ~13% avg (abstract concept difficult for small models)

3. REGRESSION WARNING
   llama3-2-3b LSP dropped from 60.4% to 2.1% (-58.3%)
   Possible causes:
   - Evaluator incorrectly disagreeing with valid LSP detections
   - Feedback loop causing detector to second-guess correct answers

### Conclusions
----------------------------------------

1. TWO-AGENT WORKFLOW IS EFFECTIVE
   The Detector-Evaluator feedback loop improves overall accuracy by an
   average of +13.5% across both models.

2. DIP DETECTION BENEFITS MOST
   DIP shows the largest gains (+60.4% avg), suggesting feedback is
   particularly effective for identifying concrete dependency issues.

3. LSP REMAINS CHALLENGING
   LSP detection stays near 0% for gemma3-4b and regresses in llama3-2-3b,
   indicating this principle requires larger models or different strategies.

4. FEEDBACK LOOP CAN CAUSE REGRESSION
   The llama3-2-3b LSP regression shows that iterative feedback can
   sometimes hurt performance when evaluator incorrectly rejects valid results.

### Recommendations
----------------------------------------

1. Use Two-Agent workflow for SRP, OCP, ISP, DIP detection
2. Consider Single-Agent or specialized prompts for LSP detection
3. If baseline accuracy < 20%, Two-Agent can provide 2-3x improvement
4. Test with larger models (8B+) for better LSP/OCP detection
